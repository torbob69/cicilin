PHASE 6 — XP & RANK SYSTEM  (Day 10)
--------------------------------------------------------------------------------

Day 10 · XP Engine + Rank + Leaderboard
  [ ] services/xp_service.py
        - add_xp(user_id, delta, reason) → log to xp_events + update user.xp
        - recalculate_rank(user) → update user.rank based on XP thresholds
            0-99=Iron, 100-299=Bronze, 300-599=Silver,
            600-999=Gold, 1000-1499=Platinum,
            1500-1999=Diamond, 2000+=Ruby
        - XP gain events (called from loan/repayment flows):
            pay_on_time → +20
            pay_early   → +35
            full_repay  → +60
        - XP loss events:
            late_1_7_days   → -40
            late_8_30_days  → -100
            default_30plus  → -250
  [ ] Daily XP drain job (APScheduler, runs at midnight):
        - Find users with at least one overdue loan
        - Apply drain per rank (Bronze:-1, Silver:-1, Gold:-2,
          Platinum:-2, Diamond:-3, Ruby:-3)
        - Call add_xp() with negative delta
  [ ] routers/users.py
        - GET /users/me/rank  (XP, rank, xp_events history)
  [ ] GET /leaderboard  (top users by XP, show username + rank badge)

  Note: APScheduler setup goes in main.py lifespan event

PHASE 7 — MONTHLY QUESTS  (Day 11)
--------------------------------------------------------------------------------

Day 11 · Quest System
  [ ] services/quest_service.py
        - QUEST_POOL: hardcoded list of 20 quests with:
            id, name_id (Bahasa), condition_type, condition_value, xp_reward
        - randomize_monthly_quests() → pick 5 from 20, store in monthly_quests
        - get_active_quests(month) → 5 quests for current month
        - check_quest_progress(user_id, month) → evaluate each condition
        - complete_quest(user_id, quest_id) → award XP, mark complete
  [ ] Monthly quest reset job (APScheduler, runs on 1st of each month):
        - Call randomize_monthly_quests()
        - Reset user_quest_progress for new month
  [ ] Daily quest evaluation job (APScheduler, runs at midnight):
        - For all users, evaluate quest conditions
        - Complete any newly-met quests and award XP
  [ ] routers/quests.py
        - GET /quests/active  (this month's 5 quests + user completion status)
